# 화면 설계

구현 기준은 `docs/mockup.html`이다. 브라우저에서 열면 모든 화면을 눌러 볼 수 있다. 이 문서는 목업에서 알 수 없는 규칙과 문구를 글로 정리한 것이다.

- 기준 화면은 **데스크톱**이다. 창을 좁혀도 깨지지 않을 정도만 대응한다.
- 디자인 방향은 사용자가 고른 레퍼런스(연두색 체크 바탕, 바인더 노트, 폴더 탭, 점선 박스, 과일 캐릭터)다.
- 화면 구성이나 디자인을 바꾸고 싶으면 구현하기 전에 사용자에게 먼저 물어본다.

## 1. 화면 목록

| 화면 | 목업에서 보는 법 |
|---|---|
| 로그인 / 회원가입 (오류 상태 포함) | 처음 열면 로그인 화면. 탭으로 회원가입 이동 |
| 정산 창 1단계 · 지난달 남은 돈 | 맨 아래 목업 도구 `정산 창 · 지난달 남은 돈 있을 때` |
| 정산 창 1단계 · 지난달 초과 | `정산 창 · 지난달 초과했을 때` |
| 정산 창 1단계 · 처음 쓰는 달 | `정산 창 · 처음 쓰는 달` |
| 정산 창 2단계 · 분류 배분 | 1단계에서 `다음` |
| 대시보드 | 로그인 후 첫 화면 |
| 달력 (이번 달: 추가·수정·삭제 / 수정 상자 열린 상태 / 수정 오류 / 오늘 이후 날짜 / 지난달: 읽기 전용) | 탭 `달력`, 날짜 선택, 연필 버튼, 금액에 `1.5` 입력 후 저장, `<` 버튼 |
| 설정 | 탭 `설정` |

## 2. 디자인 토큰

| 이름 | 값 | 쓰임 |
|---|---|---|
| 바탕 | `#D9F0BC` + 흰색 반투명 체크(44px) | 페이지 배경 |
| 종이 | `#FFFBE3` | 노트 안쪽, 활성 탭 |
| 글자 | `#2B4A22` | 본문, 테두리 |
| 보조 글자 | `#4F6B3F` | 설명, 부가 정보 |
| 점선 | `#7FB069` (노트 안쪽 점선), `#A8CB8B` (줄 구분 점선) | |
| 입력칸 | `#FFFFFF` | |
| 강조 버튼 | `#8CCB4F` 바탕, `#1F3D17` 글자 | `추가`, `다음`, `로그인` |
| 노란 칸 | `#FFF1A8` | 총 금액, 지출 입력 상자 |
| 민트 칸 | `#EAF6D6` | 남은 돈 카드, 미배분 금액 |
| 비활성 탭 | `#BFE08F` 바탕, `#7FA566` 테두리 | |
| 초과 / 오류 | `#C4213A` | 초과 표시와 오류에만 사용 |
| 비활성 버튼 | `#E3E8D5` 바탕, `#60705A` 글자, `#A9B79A` 테두리 | |

- 글꼴: 제목·강조 숫자·라벨 `Jua`, 본문 `Gowun Dodum` (Google Fonts), 대체 글꼴 `Malgun Gothic`
- 금액은 오른쪽 정렬, 숫자는 `tabular-nums`
- 노트: 바깥 테두리 4px, 모서리 28px, 안쪽 점선 2px, 모서리 18px
- 버튼은 알약 모양(3px 테두리), 입력칸은 모서리 14px(2px 테두리)
- 합계는 **이중선 아래에 크게** 보여준다. (장부 느낌)
- 초과는 빨간색만이 아니라 `-` 기호와 `초과` 라벨을 함께 쓴다.
- 키보드 포커스는 3px 테두리로 보여준다.
- 밝은 모드만 필수다. (목업에는 어두운 모드 변수도 들어 있지만 구현하지 않아도 된다.)

## 3. 공통 요소

- **폴더 탭**: 위쪽에 `대시보드`, `달력`, `설정`. 현재 탭은 종이색에 굵은 테두리, 나머지는 연두색. 오른쪽 끝에 오늘 날짜 `2026년 11월 14일 (토)` 형식
- **정산 창**: 어두운 초록 반투명 막 위에 노트 모양 창. 위에 `1 / 2 단계` 칩과 오른쪽에 `11월 첫 정산`, 그 아래 토마토 캐릭터. 닫기 버튼 없음
- **칩**: 어두운 초록 바탕에 종이색 글자의 알약 (`오늘 쓴 돈`, `이번 달 남은 돈` 등)
- **막대**: 높이 12~16px 알약, 채움 `#8CCB4F`, 초과는 빨간 테두리와 빨간 채움

## 4. 화면별 구성

### 로그인 / 회원가입

- 가운데 노트 한 장(폭 약 480px). 위에 `로그인`, `회원가입` 탭
- 토마토, `생활비 통장`, 한 줄 안내
  - 로그인: "로그인하고 이번 달 생활비를 관리해요"
  - 회원가입: "계정을 만들고 생활비 기록을 시작해요"
- 로그인: `이메일`, `비밀번호`, `로그인` 버튼, 아래에 "계정이 없나요? 회원가입"
- 회원가입: `이메일`, `비밀번호`(안내 "8자 이상으로 만들어 주세요"), `비밀번호 확인`, `회원가입` 버튼, 아래에 "이미 계정이 있나요? 로그인"
- 오류: 해당 입력칸 아래 빨간 굵은 글씨 한 줄 + 빨간 테두리. 로그인 실패는 두 칸 모두 빨간 테두리, 문구는 비밀번호 칸 아래에만
- 문구 목록은 `PRD.md` FR-1 참고
- 로그아웃 버튼은 어느 화면에도 없다.

### 정산 창 1단계

1. 윗줄: `1 / 2 단계` 칩, `11월 첫 정산`
2. 토마토 (제목 글자 없음. 초과 화면에는 제목 "지난달 정리하고 이번 달 정해요"가 있음)
3. 지난달 결과 상자
   - 남은 돈: 민트 상자, `10월 남은 돈` 칩과 `+120,000원`
   - 초과: 빨간 테두리 상자, `10월 초과 지출` 칩과 `초과` 라벨, `-85,000원` (빨간색)
   - 처음 쓰는 달: "처음 쓰는 달이라 지난달 결과가 없어요. 이번 달에 쓸 돈만 정하면 돼요." 점선 안내 상자
4. 처리 선택
   - 남은 돈: 소제목 "남은 120,000원을 어떻게 할까요?", `저금통에 저축` 입력, `다음 달로 이월` 입력
   - 초과: 소제목 "초과한 85,000원을 어떻게 할까요?", 라디오 3개 (`다음 달 총 금액에서 차감` / `그냥 두기` / `저금통에서 차감하고 나머지는 다음 달에서 차감`). 선택한 항목은 노란 칸과 굵은 테두리, 세 번째를 고르면 "저금통에서 뺄 금액 (잔액 150,000원)" 입력이 열림
5. `이번 달 총 금액`: `기본 금액` 입력, `지난달에서 이월 + ○원`, `지난달 초과분 차감 - ○원`, 이중선 아래 노란 칸에 `이번 달 총 금액 ○원`
6. 오른쪽 아래 `다음` 버튼 (조건이 안 맞으면 비활성)

- 남은 돈 화면에는 "총 ○원 − 사용 ○원" 줄, 저금통 잔액 변화 줄, 저축+이월 합계 줄, `전부 저금통`/`전부 이월` 버튼이 **없다**. (삭제하기로 한 것들)
- 조건이 안 맞아서 `다음`이 비활성일 때는 총 금액 아래 빨간 글씨로 이유를 알려준다. (합이 다름, 숫자가 아님, 총 금액 0원 이하)

### 정산 창 2단계

1. `2 / 2 단계` 칩, 토마토와 제목 "분류별로 나눠 주세요"
2. 노란 칸: `이번 달 총 금액 ○원`
3. 분류 줄마다 이름, 금액 입력(`원`), 동그란 `×` 삭제 버튼. 삭제를 누르면 그 줄이 확인 줄("○○ 분류를 삭제할까요? 이번 달부터 목록에서 빠져요." + `삭제`/`취소`)로 바뀜
4. 점선 상자: `새 분류 이름` 입력(예: 반려동물)과 `+ 분류 추가` 버튼
5. `배분 합계 ○원`, 민트 칸에 `아직 나누지 않은 금액 ○원` (크게)
6. `이전`, `저장하고 시작` (합계가 맞을 때만 활성)

- 분류 삭제 설명 문구는 화면에 두지 않는다.
- 금액이 올바르지 않을 때만 그 칸 테두리와 안내가 나온다.

### 대시보드

- 두 열. **왼쪽**: `오늘 쓴 돈 ○원` → 노란 상자 `오늘 지출 입력`(분류 칩, 금액, 메모, `추가`) → 오늘 내역(분류 라벨, 메모, 금액, `×`)
- **오른쪽**: 민트 카드 `이번 달 남은 돈`(가장 큰 숫자, 막대, "총 ○원 중 ○원 사용", "○% 썼어요") → 점선 상자 `저금통 잔액 ○원` → `분류별 남은 돈` 목록(이름, 남은 금액, 막대, "배분 ○원 · 사용 ○원")
- 초과한 분류: 이름 옆 `초과` 라벨, 금액 `-○원` 빨간색, 막대 빨간색

### 달력

- 두 열. **왼쪽**: `<` `2026년 11월` `>` 와 `이 달 쓴 돈 ○원` 칩, 요일 줄(월 화 수 목 금 토 일), 날짜 칸
- 날짜 칸: 왼쪽 위에 날짜, 오른쪽 아래에 그날 합계(`136,500원`, 없으면 연한 `0`). 쓴 날은 민트 칸과 진한 테두리, 오늘은 굵은 테두리와 `오늘`, 선택한 날은 어두운 초록 바탕
- **오른쪽**: 선택한 날짜 칩과 합계, 내역 목록, 이번 달이면 `이번 달 남은 돈 ○원`
- **이번 달, 오늘까지의 날짜**
  - 내역 줄: 분류 라벨, 메모, 금액, 동그란 연필 버튼(수정), 동그란 `×` 버튼(삭제)
  - 연필을 누르면 그 줄이 노란 `지출 수정` 상자로 바뀐다. 분류 칩, 금액 입력(`원`), 메모 입력, `취소`(종이색)와 `저장`(연두색)
  - 내역 아래 노란 `이 날 지출 추가` 상자: 분류 칩(첫 분류가 선택된 상태), 금액, 메모, 연두색 `추가` 버튼
  - 금액 오류는 입력칸 아래 빨간 글씨로 안내 (대시보드와 같은 문구)
- **미래 날짜** (시안 `달력 · 오늘 이후 날짜`): 날짜 칩과 `0원`, "이 날은 쓴 돈이 없어요.", "아직 오지 않은 날이에요.", 맨 아래 `이번 달 남은 돈 ○원`. 연필·`×` 버튼과 `이 날 지출 추가` 상자는 없다.
- **수정 오류** (시안 `달력 · 지출 수정 오류 안내`): 금액이 올바르지 않으면 금액 칸이 빨간 테두리가 되고 칸 아래에 "금액은 원 단위 숫자만 입력할 수 있어요."가 나온다.
- 지난달: 오른쪽에 점선 라벨 "지난달 기록 · 볼 수만 있어요", 연필·`×`·`이 날 지출 추가`가 없다. 가장 이른 달에서는 `<`가 비활성, 이번 달에서는 `>`가 비활성

### 설정

- 두 열. **왼쪽**: 칩 `이번 달 예산 수정`과 `2026년 11월`, `이번 달 총 금액` 입력(굵은 아래줄), `분류별 배분`(분류마다 이름과 "사용 ○원", 금액 입력), 민트 칸 `아직 나누지 않은 금액`, 안내 한 줄, `취소`와 `저장`
- **오른쪽**: 민트 카드 `저장하면 이렇게 돼요` — `이번 달 총 금액 현재 ○원 → 변경 ○원`, `이번 달 남은 돈` 큰 숫자. 아래 점선 라벨 "지난달 기록은 수정할 수 없어요"
- 안내 한 줄 예: "50,000원을 더 나눠야 저장할 수 있어요.", "총 금액보다 ○원 많아요. 줄여 주세요.", "바꾼 내용이 없어요.", "합계가 딱 맞아요. 저장할 수 있어요."
- 이미 쓴 금액보다 적게 배분했다는 경고 문구와 "이미 쓴 내역은 그대로 남고…" 문구는 화면에 두지 않는다.

## 5. 목업과 실제 구현의 차이 (바꿀 것)

| 목업 | 구현 |
|---|---|
| 날짜가 11월 14일로 고정 | `getToday()`로 실제 날짜 사용 (테스트에서는 이 함수만 바꿈) |
| 맨 아래 `목업 도구` 상자와 로그인 화면의 `연습 계정으로 로그인` | 구현하지 않는다. (정산 창은 매달 첫 접속에 자동으로 뜬다.) |
| 샘플 지출·샘플 계정 | 샘플 데이터 없음. 처음 가입하면 빈 상태에서 시작 |
| 이메일·비밀번호를 브라우저에 그대로 저장 (연습용) | Supabase Auth가 비밀번호를 해시로 저장 |
| 지출·설정을 브라우저(localStorage)에 계정별로 저장 | `loadData`/`saveData`를 거치다가 마지막에 Supabase 호출로 교체 |
| 정산 직후, 설정 저장 직후에 대시보드 위쪽에 뜨는 안내 줄 | 있어도 되고 없어도 된다. (화면 설계에는 없는 목업 전용 안내) |
| 정산 1단계에서 지난달이 0원일 때 | 설계 시안이 없다. 지난달 처리 부분 없이 총 금액만 보여주고 "처음 쓰는 달" 문구는 쓰지 않는다. |
| 달력에서 달을 바꾸면 날짜가 선택되지 않은 상태로 시작 | 같다. (화면 설계의 지난달 시안은 24일이 선택된 예시 상태) |
